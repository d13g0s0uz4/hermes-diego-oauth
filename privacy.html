Privacy policy

Last updated: 2026-10-25.

hermes-diego is a personal, single-user application. Its only user is its owner, Diego Souza. It is not available to the public.

What it accesses

  • Gmail, read-only (gmail.readonly): messages, to summarize them for the owner.
  • Google Calendar, read-only (calendar.readonly): events, to summarize the owner's schedule.

It cannot send, modify or delete email, calendar events or any other Google data.

How the data is used

The data is used only to answer the owner's own requests, in his private Telegram chat with the assistant, which receives summaries, not message bodies. To produce a summary, the relevant content is sent to the language model provider that powers the assistant (Anthropic), through Cloudflare AI Gateway with request and response logging turned off. It is not sold, shared with anyone else, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

OAuth credentials are kept in a secrets manager and in memory on the owner's server. The application does not keep a copy of the mailbox or calendar.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.
